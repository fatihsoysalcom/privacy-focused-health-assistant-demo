# Privacy Focused Health Assistant Demo

This example demonstrates a privacy-focused AI health assistant using a simple, local, rule-based system. It showcases how user health queries can be processed entirely on-device without sending sensitive data to external servers, thus prioritizing user privacy. The code emphasizes local data handling and provides simulated health advice based on a predefined knowledge base.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt.
3. Run the script using `python main.py`.
4. Type your health-related questions in Turkish and press Enter.
